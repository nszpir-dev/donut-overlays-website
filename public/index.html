Questions people ask

Does this work on Donut SMP?

Yes. It reads the chat log your own client writes, so it needs nothing from the server and breaks no rules.

How fast is it really?

Payment to pixels is roughly a tenth of a second. Viewers see it a few seconds later because that is how long every platform holds video.

Do I need OBS?

Only for Twitch and YouTube. TikTok LIVE Studio takes the link directly.

What if my server words payments differently?

Send us the line and we will add it. Recognising new payment formats takes a day, not a release.

Can I run two games at once?

Not on one account — both would be reading the same payments and fighting over them. Run one per stream.

What happens when I cancel?

Your overlay links stop loading at the end of the paid period. Settings are kept for 90 days if you come back.
